n8n is a workflow automation tool that lets you connect apps and services by joining nodes on a visual canvas. Every workflow starts with a trigger node, such as a schedule that runs at a set time, a webhook that waits for an incoming request, or a form that a user submits. After the trigger, the data moves from node to node, and each node performs one step, like fetching an RSS feed, calling an AI model, or sending an email. Expressions let a node use data from earlier nodes, for example by inserting the text from a form into a prompt. An error workflow can be linked to another workflow so that it sends an alert when a scheduled run fails. n8n can be self-hosted, and it is popular for building AI automations that connect language models to everyday tools.
