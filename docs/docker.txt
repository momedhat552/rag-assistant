Docker is a tool that packages an application together with everything it needs to run, including the programming language, libraries, and settings, into a single unit called a container. Before containers, developers often faced the problem that code worked on their own computer but failed on a colleague's machine or on a server because of small differences in setup. A container solves this by making the environment identical everywhere. Containers are lightweight because they share the host computer's operating system instead of running a full virtual machine, so they start in seconds and use fewer resources. A Dockerfile is the recipe that describes how to build an image, and an image is the packaged copy from which containers are started. Today, most companies use Docker to deploy applications, and it is a common requirement in software and AI engineering jobs.
