A firewall is a security device that controls network traffic by allowing or blocking it according to a set of rules. These rules are called security policies, and each one usually matches traffic by source, destination, service or port, and then applies an action such as permit or deny. Most firewalls use a default deny approach, which means that any traffic not explicitly allowed is blocked. A stateful firewall keeps track of active connections, so it can automatically allow the reply traffic for a connection that was started from inside the network. Networks are often divided into security zones, such as a trusted internal zone, an untrusted internet zone, and a DMZ where public-facing servers are placed. Good security operations include logging firewall events, reviewing alerts, and following an incident response process to contain and investigate suspicious activity.
